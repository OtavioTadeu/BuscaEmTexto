# Busca em Texto - Algoritmos e Estruturas de Dados II

Projeto prático desenvolvido para a disciplina de Algoritmos e Estruturas de Dados II da Faculdade COTEMIG (Semestre 2026/1).

## Sobre o Projeto

Este projeto é uma aplicação desktop Windows Forms (C#) projetada para demonstrar e comparar a eficiência de diferentes algoritmos de busca em texto. A aplicação permite abrir arquivos de texto ou _rich text_ e pesquisar palavras ou padrões aplicando os seguintes métodos:

- **Força Bruta** (Suporta o uso do caractere `?` como curinga universal)
- **Rabin-Karp**
- **Knuth-Morris-Pratt (KMP)**
- **Boyer-Moore**

## Principais Funcionalidades

- **Leitura de Arquivos:** Suporte à abertura de arquivos padrão de texto (`.txt`) e _Rich Text Format_ (`.rtf`).
- **Destacar Ocorrências:** Ao realizar uma busca, todas as ocorrências encontradas da palavra no texto são destacadas com uma cor de fundo.
- **Janela de Busca Avançada:**
  - Suporte a busca **Case Sensitive** (diferenciando letras maiúsculas e minúsculas).
  - Capacidade de **Substituir Todos**, trocando a string localizada por um novo termo desejado, de maneira dinâmica no editor.

## Tecnologias Utilizadas

- **Linguagem:** C# (.NET Framework)
- **Interface:** Windows Forms
